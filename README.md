# Local Video Studio Releases

Public installable builds of **Local Video Studio** for Apple Silicon macOS.

## Install

1. Open the [latest release](https://github.com/Tap-Kim/local-capcut-releases/releases/latest).
2. Download the **arm64 DMG**.
3. Open the DMG and copy **Local Video Studio.app** to Applications.
4. On first launch, if macOS blocks the unsigned build, Control-click the app → **Open**, or use **System Settings → Privacy & Security → Open Anyway**.

The ZIP is provided for users who prefer the raw app bundle. SHA256 checksums and `release-manifest.json` are attached to each release.

Local Video Studio can use **Voiz Studio 0.0.25+** for local TTS. When Voiz is installed in Applications, the desktop app can automatically start and recover its local service.

Current public release: **v0.0.36**.
